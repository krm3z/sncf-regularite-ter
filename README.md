# Régularité des TER en Auvergne-Rhône-Alpes

## Problématique
Comment évolue la régularité des TER en Auvergne-Rhône-Alpes depuis 2013 par rapport aux autres régions ?

## Données
Régularité mensuelle TER, SNCF, sur data.gouv.fr (janvier 2013 à août 2026, 2 380 lignes), sous licence ODbL.
